# Diálisis Fácil

Guía visual paso a paso (40 pasos) para la diálisis peritoneal, pensada para que una persona lea y le dicte los pasos al paciente.

Sitio en producción: https://dialisisfacil.com/

## Estructura

- `index.html` — toda la página (HTML, CSS y JS en un solo archivo).
- `img/pasoN.png` y `vid/pasoN.mp4` — imágenes/videos opcionales por paso (la página los busca si existen).

## Ver localmente

Abrir `index.html` en el navegador, o servirlo:

```bash
npx serve .
```

## Publicar

El sitio corre en un servidor Apache como archivo estático: subir `index.html` (y `img/`, `vid/` si existen) a la raíz del hosting.

> Aviso: guía de ayuda no oficial e ilustrativa. No sustituye las indicaciones médicas.
